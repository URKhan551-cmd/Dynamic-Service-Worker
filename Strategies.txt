CAHCE FIRST 
request > cache ? if yes > cache 
                 if no > Network > cache > response

images, fonts, version js, versioned css



NETWORK FIRST 
request > 
          Network > SUCCESS > response + cache
                    FAIL  > cache

api data / dynamic pages /  frequently changing content


NETWORK ONLY
request > Network > response

no cache data


CACHED ONLY
request > cache > response

useful for pre CACHED during installaton of an app

request > cache  > return immediately > meanwhile  > network > update Cache
